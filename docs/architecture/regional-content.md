# Regional and Global Ownership Boundary

Access currently serves Auth APP/ORG, Visa APP/ORG, and its six operator tools. It no longer serves
Core, Warp, Palm, Side, Docs, News, Help, Info, or other regional/content product routes. External
repositories own their RP routes, callbacks, sessions, and user interfaces.

The accepted global/regional database ownership decisions remain relevant to persisted data, but
they do not establish local HTTP routes. Publishing models, migrations, and database connections
remain in Access pending the separate model/database usage report. No content read API is currently
served by this repository.

For the current local surface map, see [`Access Surface Ownership`](acme-sign-core-base-port.md).
Earlier route and delivery details remain in accepted ADRs and dated implementation records; read
them as history rather than current Access behavior.
