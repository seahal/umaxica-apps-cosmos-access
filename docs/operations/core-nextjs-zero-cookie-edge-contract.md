# Core Next.js Edge Contract Retirement

Core is not a current Access surface after the 2026-11-10 route/controller reset. Access has no Core
Rails origin routes or controllers to pair with the Next.js edge contract formerly described here.
This file is retained as a link target for earlier records; it is not current Access deployment
guidance.

The prior Core cookie-stripping and Cloudflare verification procedure applies only if the external
Core owner separately maintains that architecture. Access does not own or verify that edge. The
historical Core RP registration, if used by an external client, remains an OIDC registration and
does not restore Core routes in this repository.
